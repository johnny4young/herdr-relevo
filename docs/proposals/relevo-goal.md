# Goal: review work from one Inbox

Bring existing PRs, local work and human decisions together while preserving Herdr spaces, terminals, accounts and Relevo review actions.

A goal records an expected outcome, owner, priority, optional existing lead, linked work, criteria and plan. Step states are Pending, In progress, Needs review and Validated. Goal states are explicit; inactive terminals and addressed cards do not establish completion.

## Current scope

- Classic and Goals views share existing work and actions.
- Focus isolates a goal's linked work, with All work restoring the queue.
- Draft and addressed work remain available through folds.
- Revision-bound evidence links and feedback are separate from approvals.
- Version checks protect saved edits from stale writers.
- File-scoped installation provides rollback without resetting accounts or sessions.

## Further work

The [local workflow runtime](workflow-runtime.md) adds explicit task ownership, coordinator dispatch, delivery records, restart reconciliation, round/time limits, local artifact fingerprints, batches and accepted scoped preferences. Assigning a lead alone does not start execution. Automatic goal decomposition, provider-enforced money budgets, automatic visual artifact generation and built-in speech capture remain outside this increment; native text fields support system dictation.
